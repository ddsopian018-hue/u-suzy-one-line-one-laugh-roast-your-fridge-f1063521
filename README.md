A one-line roast of my own fridge. The line is 187 characters: *"My fridge is the only roommate who never pays rent, never does dishes, and still flips its light on at 2 a.m. to watch me eat cold pizza standing over the sink like a disappointed parent."* The roast is built on things only a fridge does — flipping its light on the moment the door opens, humming in the corner — and the laugh lands on the last beat, where the appliance turns into a disappointed parent watching the 2 a.m. cold-pizza ritual.

## Run it

Requires Node 22+ (runs the TypeScript entry directly).

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

This writes the roast line (no trailing newline) to `output/entry.txt`, after gate-checking it: 1–200 characters, valid UTF-8, a single line, not whitespace-only.
